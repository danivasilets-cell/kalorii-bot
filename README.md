# Калории — Telegram Mini App

Трекер питания: дневник, КБЖУ, вода, вес, статистика, рецепты, план питания, список покупок,
ИИ-распознавание еды по фото, голосовой ввод, ИИ-помощник, сканер штрихкодов, напоминания.

## Архитектура
- **Мини-приложение** — статическая страница на GitHub Pages (`index.html`, `*.js`, `style.css`).
- **Данные пользователя** — Telegram CloudStorage (у каждого свои, синхронизируются между устройствами).
  Ключи: `d_YYYYMMDD` (день), `profile`, `recent`, `custom`, `weights`, `ach`, `ds_<id>` (блюда),
  `p_YYYYMMDD` (план), `shop`, `chat`.
- **Сервер** — Cloudflare Worker (`bot/worker.js`): бот, команды владельца, глобальные настройки,
  ИИ (Workers AI), напоминания по cron, экспорт файлов в чат. Подпись Telegram `initData` проверяется
  на сервере для всех запросов.

## Файлы
| Файл | Что внутри |
|---|---|
| `foods.js` | встроенная база (~660 продуктов, 24 категории) |
| `recipes.js` | 28 рецептов, КБЖУ считается из базы |
| `app.js` | ядро: хранилище, дневник, добавление еды, профиль, достижения, панель владельца |
| `stats.js` | статистика 7/30/90 дней, анализ прогресса, экспорт CSV/отчёта |
| `menu.js` | рецепты, избранные блюда, план питания, список покупок |
| `ai.js` | фото → продукты, голос/текст → продукты, ИИ-помощник |
| `scan.js` | сканер штрихкодов (камера, фото, ручной ввод) |
| `notif.js` | меню приёма пищи, вода, напоминания |
| `bot/worker.js` | сервер (Cloudflare Worker) |

## Настройка сервера (Cloudflare)
Переменные: `BOT_TOKEN` (secret), `OWNER_ID`, `WEBHOOK_SECRET` (secret).
Привязки: KV `DB`, Workers AI `AI`. Cron: `* * * * *`.
После деплоя: `https://<воркер>/setup?secret=<WEBHOOK_SECRET>`.
