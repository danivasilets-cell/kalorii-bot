# Калории — мини-приложение для Telegram

Подсчёт калорий и БЖУ, вода, вес, история. Полностью бесплатно, без своего сервера:
- приложение — статическая страница на GitHub Pages;
- данные — Telegram CloudStorage (у каждого пользователя свои, видны только ему);
- база продуктов — встроенная + Open Food Facts.
